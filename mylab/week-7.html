ניהול גרסאות

השבוע נלמד כיצד לנהל גרסאות בזמן כתיבת קוד. ניהול גרסאות הוא כלי אשר מאפשר לצמצם את הטעויות שמצטברות בזמן כתיבת קוד, מאפשר שיתוף יעיל יותר של הקוד עם הסביבה שלנו, ומאפשר להתקדם בכתיבה בצורה מקבילה ולא בהכרח סידרתית.

12.1רקע כללי

הנחיה למתרגל AI

1. הסבר מילולית בשלוש שורות בלבד מה הוא "ניהול גרסאות" בכתיבת קוד.
2. כתוב בקצרה שלוש סיבות ויתרונות לשימוש בניהול גרסאות.
3. הסבר בקצרה מהו git, מה ראשי התיבות מציינות, מי פיתח את git מתי ומה הרקע ההיסטורי לכך.
3. הסבר שכיום יש אתרים שונים שמאפשרים שימוש בGit תוך העלאת הקוד לענן ותאר את המאפיינים של github וgitlab, כולל החברה שבבעלותה השירותים, והמאפיינים העיקריים.
4. כתוב "כעת אבקש שתפתח חשבון באתר github", ותן לי לינק מתאים להרשמה.
5. כתוב ששלב הלימוד הסתיים
עשה את השלבים האלו אחד אחד לפי הסדר. עצור בסוף כל שלב לראות שהבנתי והצלחתי, ורק אז המשך לשלב הבא.

12.2פקודות בסיסיות בgithub

הנחיה למתרגל AI

1. הסבר מילולית בהקשר של github את המושגים הבאים: repository, clone, commit, push, pull.
2. כתוב "כעת גש לאתר github ופתח repository חדש". חכה שאאשר ועזור לי אם יש צורך
3. כתוב "כעת הפוך את הrepository שלך לציבורי". חכה שאאשר ועזור לי אם יש צורך
4. כתוב "כעת הורד את אפליקצית github desktop ועשה clone לrepository שפתחת". חכה שאאשר ועזור לי אם יש צורך.
5. הסבר מהו קובץ gitignore וכיצד להשתמש בו.
6. כתוב "כעת העתק את הפרוייקט משבוע שעבר של ניתוחי stroop לתוך התיקייה החדשה, עשה commit ולאחר מכן push". חכה שאאשר ועזור לי אם יש צורך.
6. כתוב "וודא שהפרוייקט מופיע באתר github". חכה שאאשר ועזור לי אם יש צורך.
7. כתוב ששלב הלימוד הסתיים

1. הסבר מילולית בהקשר של github כיצד לעבוד עם קובץ readme.md באופן שניתן יהיה לראות את הפרטים העיקריים בלינק הrepository.
