8.1הבדל בין שתי קבוצות בלתי תלויות

הנחיה למתרגל AI

מודל רגרסיה לבחינת הבדל בין שתי קבוצות
1. תן דוגמא בR שבה אתה מייצר factor של המשתנה "treatment" עם הרמות placebo, active. ובנוסף משתנה y שנדגם מהתפלגות נורמלית עם ממוצע 50 וס"ת 25. תן רק את הקוד, ללא הסברים מילולים כלל וכתוב "קודם כל אני מייצר כאן נתונים כדי שנוכל להעזר בהם לבצע ניתוח רגסיה שכיחותנית. האם יש לך שאלות לגבי הקוד"?
2. תן דוגמא בR כיצד לערוך להשתמש בפקודת lm() כיצד להתאים מודל עם הנוסחא y ~ treatment, ולבחון את התוצאה באמצעות summary. הראה שניתן להגיע למקדמים באמצעות $coef
3. כתוב ששלב הלימוד הסתיים
עשה את השלבים האלו אחד אחד לפי הסדר. עצור בסוף כל שלב לראות שהבנתי והצלחתי, ורק אז המשך לשלב הבא.

המטלה השבועית

המטלה השבועית (שבוע 10) – רגרסיה לינארית, משתנים פקטוריאליים ורציפים, וניבוי

קובץ הנתונים כולל את המשתנים:

זמן הכנה לבחינה, סוג טיפול לחרדה (מיינדפולנס מול פלאסבו), מגדר, ציון המבחן, ודירוג החרדה.

מטרת המטלה היא לתרגל ניתוח נתונים באמצעות רגרסיה לינארית, כולל תיאור נתונים, בדיקת אפקטים של משתנים קטגוריאליים, עבודה עם מודל פאקטוריאלי, ושימוש במודל לצורך ניבוי.

קובצי נתונים: Exam-Anxiety.csv

חלק א – תיאור התפלגות החרדה והציונים

  1. עשו שימוש ביכולות הגרפיות של R על מנת להציג את פיזור ציוני החרדה, ציוני המבחן. נסו להקפיד על תרשים אחד עם שני פאנלים, כותרות, טווח צירים, שימוש נכון בצבעים, התצפיות עצמן וסטטיסטיקה גרפית מסכמת
  2. הוסיפו סטטיסטיקה תאורית מילולית על מנת לתאר את ההתפלגויות הללו.

חלק ב – אפקט המגדר

  1. חשבו באמצעות רגרסיה את מקדם אפקט המגדר על ציוני החרדה ודווחו על גודלו.
  2. חשבו באמצעות מודל רגרסיה חדש את האפקט הפאקטוריאלי של מגדר, קבוצת טיפול, והאינטראקציה בניהם ודווחו על המקדמים. הסבירו במילים שלכם את משמעות המקדמים.
  3. כעת חשבו באמצעות מודל רגרסיה חדש, את האפקט של קבוצת הטיפול על דירוגי החרדה, כאשר אתם שולטים בזמן ההכנה לבחינה. שימו לב לעשות שימוש בשני אפקטים עיקריים, ללא אינטראקציה בניהם. דווחו על אפקט הטיפול לאחר שלמעשה שלטתם בזמן ההכנה לבחינה.
  4. בונוס (רשות ולא לבחינה): לימדו בכוחות עצמכם כיצד ניתן לתאר באמצעות שילוב בין חבילת emmeans לבין חבילת ggplot בצורה גרפית את התוצאות

חלק ג - ניבוי

  1. כעת צרו מודל רגרסיה נוסף ואחרון שבו אתם מנבאים את ציון הבחינה רק כפונקציה של זמן ההכנה עבור נבדק 1 עד 90.
  2. עשו שימוש במודל זה כדי להוסיף עמודת “ניבוי” שבה יש ציון מנובא עבור נבדק 91 עד האחרון.
  3. צרו תרשים שבו בציר האנכי הציון המנובא ובציר האופקי הציון המתוצפת של כל נבדק ממספר 91 עד האחרון.

כותרות הקוד: השתמשו בפורמט הכותרות של הקורס, וכתבו בתחילת הקובץ את שם הקורס, השבוע, מספר תעודת הזהות שלכם ושמכם.

# ============================================================
# שבוע 10
# ============================================================

library(dplyr)
library(ggplot2)
library(readr)

# ============================================================
# חלק א – תיאור התפלגות החרדה והציונים
# ============================================================

df <- read_csv("data/week10_exam_anxiety.csv")

# הצצה מהירה
head(df)
str(df)
dim(df)
summary(df)

# הנחות על שמות עמודות נפוצים
# anxiety = דירוג חרדה
# exam_score = ציון מבחן
# gender = מגדר
# treatment = קבוצת טיפול
# study_time = זמן הכנה
#
# אם אצלך השמות שונים, פשוט תחליף כאן למטה בכל הקוד.

# 1. תרשים אחד עם שני פאנלים: חרדה וציון
df_long <- data.frame(
  value = c(df$anxiety, df$exam_score),
  measure = c(
    rep("Anxiety", nrow(df)),
    rep("Exam score", nrow(df))
  )
)

ggplot(df_long, aes(x = value)) +
  geom_histogram(bins = 30) +
  labs(
    title = "Distributions of Anxiety and Exam Scores",
    x = "Value",
    y = "Count"
  ) +
  theme_minimal() +
  facet_wrap(~measure, scales = "free_x")

# תוספת: פיזור נקודות עם סטטיסטיקה גרפית מסכמת
ggplot(df, aes(x = anxiety, y = exam_score)) +
  geom_point(alpha = 0.6) +
  geom_smooth(se = FALSE) +
  labs(
    title = "Exam score as a function of anxiety",
    x = "Anxiety",
    y = "Exam score"
  ) +
  theme_minimal() +
  xlim(range(df$anxiety, na.rm = TRUE)) +
  ylim(range(df$exam_score, na.rm = TRUE))

# 2. סטטיסטיקה תיאורית מילולית
desc <- df |>
  summarise(
    anxiety_mean = mean(anxiety, na.rm = TRUE),
    anxiety_sd   = sd(anxiety, na.rm = TRUE),
    anxiety_med  = median(anxiety, na.rm = TRUE),
    anxiety_min  = range(anxiety, na.rm = TRUE)[1],
    anxiety_max  = range(anxiety, na.rm = TRUE)[2],
    exam_mean    = mean(exam_score, na.rm = TRUE),
    exam_sd      = sd(exam_score, na.rm = TRUE),
    exam_med     = median(exam_score, na.rm = TRUE),
    exam_min     = range(exam_score, na.rm = TRUE)[1],
    exam_max     = range(exam_score, na.rm = TRUE)[2]
  )

print(desc)

cat(
  "Anxiety: mean =", desc$anxiety_mean,
  ", SD =", desc$anxiety_sd,
  ", median =", desc$anxiety_med,
  ", range =", desc$anxiety_min, "to", desc$anxiety_max, "\n"
)

cat(
  "Exam score: mean =", desc$exam_mean,
  ", SD =", desc$exam_sd,
  ", median =", desc$exam_med,
  ", range =", desc$exam_min, "to", desc$exam_max, "\n"
)

# ============================================================
# חלק ב – אפקט המגדר
# ============================================================

# ודאו ש-gender ו-treatment פקטורים
df <- df |>
  mutate(
    gender = as.factor(gender),
    treatment = as.factor(treatment)
  )

# 1. מקדם אפקט המגדר על חרדה
m_gender_anxiety <- lm(anxiety ~ gender, data = df)
print(coef(m_gender_anxiety))

cat("Gender effect on anxiety (coefficients):\n")
print(coef(m_gender_anxiety))

# 2. מודל עם מגדר, טיפול, ואינטראקציה
m_full <- lm(anxiety ~ gender * treatment, data = df)
print(coef(m_full))

cat("\nInterpretation guide:\n")
cat("Intercept: mean anxiety in the reference gender and reference treatment group.\n")
cat("gender...: difference between the other gender and reference gender within reference treatment.\n")
cat("treatment...: difference between the other treatment and reference treatment within reference gender.\n")
cat("gender...:treatment...: extra difference beyond adding the two main effects.\n")

# 3. אפקט טיפול על חרדה עם שליטה בזמן הכנה (ללא אינטראקציה)
m_treat_control <- lm(anxiety ~ treatment + study_time, data = df)
print(coef(m_treat_control))

cat("\nTreatment effect controlling for study_time (coefficients):\n")
print(coef(m_treat_control))

# ============================================================
# חלק ג – ניבוי
# ============================================================

# 1. מודל עבור נבדקים 1 עד 90: ציון מבחן כפונקציה של זמן הכנה
df_train_90 <- df |>
  filter(subject >= 1) |>
  filter(subject <= 90)

m_pred <- lm(exam_score ~ study_time, data = df_train_90)
print(coef(m_pred))

# 2. הוספת עמודת ניבוי עבור נבדקים 91 עד האחרון
df_test_91 <- df |>
  filter(subject >= 91)

pred_91 <- predict(m_pred, newdata = df_test_91)

df_test_91 <- df_test_91 |>
  mutate(predicted_score = pred_91)

# 3. תרשים: מנובא בציר Y ומתוצפת בציר X, עבור 91 עד האחרון
ggplot(df_test_91, aes(x = exam_score, y = predicted_score)) +
  geom_point(alpha = 0.7) +
  geom_abline() +
  labs(
    title = "Predicted vs Observed Exam Scores (Subjects 91+)",
    x = "Observed exam score",
    y = "Predicted exam score"
  ) +
  theme_minimal()
