8.4יצירת נתונים מלאכותיים

הנחיה למתרגל AI

1. הסבר על החשיבות של שימוש בנתונים מלאכותיים ככלי להבנה סטטיסטית
1. תן דוגמה בR שבה אתה מייצר משתנה תלוי y על בסיס משתנה איקס אחר בהתאם למקדם רגרסיה. הסבר שורה אחר שורה מה אתה עושה.
1. תמחיש בעזרת מדד R בריבוע איך היעדר הוספת רעש דגימה לייצור המשתנה התלוי, מאפשרת לנו להעריך בצורה מושלמת את השונות בy. תסביר מה הכוונה בהוספת רעש דגימה נורמלי, תמחיש שזה בדיוק כמו שדגמנו עד כה בעזרת rnorm.
1. בקש ממני להוסיף לקוד שנתת עד כה דגימה של רעש לתוך משתנה הy, ולהעריך את הרגרסיה מחדש.
1. חכה לכל התשובות ואז כתוב ששלב הלימוד הסתיים.
1. עשה את השלבים האלו אחד אחד לפי הסדר. עצור באופן תכוף בכל שלב לראות שהבנתי והצלחתי, ורק אז המשך לשלב הבא. הקפד על כתיבה בעברית מימין משמאל, גם כשיש אותיות באנגלית במשפט.

8.10השוואת טיב התאמה (In-sample)

הנחיה למתרגל AI

1. תתן דוגמה לקוד בR שממחיש איך מודל מורכב יותר מצליח להגיע למדד R בריבוע גדול יותר. תחזור על הקשר בין R בריבוע לבין אחוז שונות מוסברת.
1. כעת תראה שגם הוספה של משתנה X2 שאין לו קשר כלל לY גורמת לעלייה (אמנם קטנה) במדד הR בריבוע ותסביר למה.
1. הסבר על מדדי טיב ההתאמה R^2 adjusted וAIC.
1. תבחן הבנה תיאורטית של עיקרון הפרסימוניות, תדגיש שמדובר בכלל אצבע ולא בעיקרון לוגי, ותמחיש כיצד הוא בא לידי ביטוי במשוואת הAIC.
1. חכה לכל התשובות ואז כתוב ששלב הלימוד הסתיים.
1. עשה את השלבים האלו אחד אחד לפי הסדר. עצור באופן תכוף בכל שלב לראות שהבנתי והצלחתי, ורק אז המשך לשלב הבא. הקפד על כתיבה בעברית מימין משמאל, גם כשיש אותיות באנגלית במשפט. אל תשתמש במודלים עם פולינומים. רק הוספת משתני X נוספים.

8.9חלוקה ל־Train / Test והערכת ניבוי (Out-of-sample)

הנחיה למתרגל AI

1. תסביר את העיקרון של הערכת ניבוי על נתונים שהמודל לא לקח בחשבון בעת התאמת המודל, לעומת טיב התאמה לנתונים שהמודל התאמן עליהם.
1. תייצר קוד R שמחלק נתוני רגרסיה ל80% סט אימון ו20% סט מבחן. תוודא שאני מבין איזה נתונים אני צריך להכניס כדאטה לרגרסיה. תסביר מה העיקרון מאחורי חלוקה של הדאטה לסט אימון וסט מבחן. תסביר את החשיבות של חוסר תלות בין נתוני האימון לבין נתוני המבחן, עם דוגמה חיובית לחלוקה ודוגמה שלילית לחלוקה (שבה מידע מסט האימון פולש לסט המבחן).
1. תסביר בפשטות מה זה SSE ומה זה MSE.
1. בעזרת קוד R, תשווה את הMSE של הניבוי על סט האימון לעומת על סט המבחן.
1. תסביר את העקרונות של אנדר פיטינג, אובר פיטינג. תשתמש במונחים של הטיה (bias) ושונות (variance) ותתאר את הטריידאוף ביניהם.
1. חכה לכל התשובות ואז כתוב ששלב הלימוד הסתיים.
1. עשה את השלבים האלו אחד אחד לפי הסדר. עצור באופן תכוף בכל שלב לראות שהבנתי והצלחתי, ורק אז המשך לשלב הבא. הקפד על כתיבה בעברית מימין משמאל, גם כשיש אותיות באנגלית במשפט. אל תשתמש במודלים עם פולינומים. רק הוספת משתני X נוספים.

המטלה השבועית

המטלה השבועית (שבוע 11) – השוואת מודלים

את קובץ הנתונים תייצרו בעצמכם, כחלק מהמטלה.

במטלה זו תתנסו בהשוואה בין מודלים שונים, תוך שימוש במדדי טיב התאמה ובמדדי ביצועי ניבוי אמפיריים. מטרת המטלה היא להבין את המתח בין התאמה לנתונים לבין הכללה לנתונים חדשים, ואת תופעת התאמת היתר (overfitting).

חלק א - יצירת נתונים מלאכותיים

בתחילת הקובץ, יש לייצר בעצמכם דאטה פריים עם 200 נבדקים באמצעות R שבו המשתנה התלוי (ציון הבחינה) בנוי בצורה הבאה:

  • ישנם 3 משתנים בלתי-תלויים שאכן משפיעים על ציון הבחינה, כלומר שמקדמי הרגרסיה עבורם יהיו שונים מ0:
    • זמן הכנה לבחינה בשעות (מתפלג נורמלית עם ממוצע וס"ת לבחירתכם, הימנעו מערכים שליליים)
    • רמת חרדת בחינות (מתפלג נורמלית עם ממוצע וס"ת לבחירתכם, הימנעו מערכים שליליים)
    • איכות שינה (מתפלג נורמלית עם ממוצע וס"ת לבחירתכם, הימנעו מערכים שליליים)
  • ישנם 3 משתנים מקריים שאין להם קשר למשתנה התלוי (ציון הבחינה), כך שמקדמי הרגרסיה עבורם יהיו שווים ל0:
    • יד דומיננטית (משתנה בינארי של 0/1)
    • העדפה מוזיקלית (משתנה עם 3 קטגוריות - "רוק", "פופ", "קאנטרי").
    • זמן מסך בסופי שבוע (מתפלג נורמלית עם ממוצע וס"ת לבחירתכם, הימנעו מערכים שליליים)
  • לבסוף, נוסיף לכל ציון בחינה רעש מקרי עבור כל נבדק שנדגם מהתפלגות נורמלית (בעזרת rnorm)

לאחר שהגדרתם את המשתנים הבלתי-תלויים בעלי ההשפעה, המשתנים המקריים, ואת הרעש המקרי, צרו את המשתנה התלוי שלכם לפי המשוואה הזו:

exam_score = b0+b1*study_time+b2*test_anxiety+b3*sleep_quality+noise

  • בחרו עצמאית מקדמים (בטאות) שאינם 0 למשתנים המסבירים, מקדמים של 0 למשתני הרעש, והוסיפו רעש רנדומלי לציון הסופי על ידי דגימה מהתפלגות נורמלית.

יש לוודא ש:

  • רק חלק מהמשתנים משפיעים באמת על exam_score
  • המשתנים המקריים אינם תורמים לניבוי האמיתי
  • קיים רעש אקראי בנתונים

חלק ב – בניית מודלים

התאימו את שלושת המודלים הבאים לנתונים:

  1. מודל בסיסי exam_score כפונקציה של study_time
  2. מודל עם כלל המשתנים הרלוונטיים exam_score כפונקציה של:
    study_time
    test_anxiety
    sleep_quality
  3. מודל מורחב (כולל משתנים מקריים) אותו מודל כמו בסעיף 2, בתוספת:
    dominant_hand
    music_preference
    screen_time_weekend

חלק ג – השוואת טיב התאמה (In-sample)

  1. עבור כל אחד מהמודלים חשבו ודווחו על מדדי:

R-squared

Adjusted R-squared

AIC

עבור כל מדד צרו גרף עמודות המראה את ציוני טיב ההתאמה בציר ה-y ובציר האיקס את שלושת המודלים.

חלק ד – חלוקה ל־Train / Test והערכת ניבוי (Out-of-sample)

  1. חלקו את הנתונים באופן אקראי ל:
    • סט אימון (80%)
    • סט בדיקה (20%)
  2. התאימו מחדש את שלושת המודלים רק על סט האימון
  3. הפיקו ניבויים עבור סט הבדיקה בלבד
  4. עבור כל מודל חשבו על סט הבדיקה את סכום השגיאות הריבועיות בין הערכים המנובאים על ידי המודל לבין הערכים האמיתיים של המשתנה התלוי.
  5. צרו גרף עמודות המראה את ציון איכות הניבוי בציר ה-y ובציר האיקס את שלושת המודלים.

# ============================================================
# שבוע 11
# ============================================================

library(dplyr)
library(ggplot2)

# ============================================================
# חלק א – יצירת נתונים מלאכותיים
# ============================================================

n <- 200

# משתנים משפיעים
study_time    <- rnorm(n, mean = 20, sd = 5)
test_anxiety  <- rnorm(n, mean = 50, sd = 10)
sleep_quality <- rnorm(n, mean = 7,  sd = 1.5)

# מניעת ערכים שליליים
study_time    <- ifelse(study_time < 0, 0, study_time)
test_anxiety  <- ifelse(test_anxiety < 0, 0, test_anxiety)
sleep_quality <- ifelse(sleep_quality < 0, 0, sleep_quality)

# משתנים מקריים
dominant_hand <- rbinom(n, 1, 0.5)

music_preference <- sample(
  c("rock", "pop", "country"),
  size = n,
  replace = TRUE
)

screen_time_weekend <- rnorm(n, mean = 5, sd = 2)
screen_time_weekend <- ifelse(screen_time_weekend < 0, 0, screen_time_weekend)

# רעש מקרי
noise <- rnorm(n, mean = 0, sd = 5)

# מקדמים אמיתיים
b0 <- 50
b1 <- 1.5     # study_time
b2 <- -0.4    # test_anxiety
b3 <- 2.0     # sleep_quality

# משתנה תלוי
exam_score <- b0 +
  b1 * study_time +
  b2 * test_anxiety +
  b3 * sleep_quality +
  noise

# יצירת דאטה פריים
df <- data.frame(
  exam_score,
  study_time,
  test_anxiety,
  sleep_quality,
  dominant_hand,
  music_preference,
  screen_time_weekend
)

# ============================================================
# חלק ב – בניית מודלים
# ============================================================

# מודל 1 – בסיסי
m1 <- lm(exam_score ~ study_time, data = df)

# מודל 2 – משתנים רלוונטיים
m2 <- lm(exam_score ~ study_time + test_anxiety + sleep_quality, data = df)

# מודל 3 – מודל מורחב עם משתנים מקריים
m3 <- lm(
  exam_score ~ study_time + test_anxiety + sleep_quality +
    dominant_hand + music_preference + screen_time_weekend,
  data = df
)

# ============================================================
# חלק ג – השוואת טיב התאמה (In-sample)
# ============================================================

# חילוץ מדדים
r2_1  <- summary(m1)$r.squared
r2_2  <- summary(m2)$r.squared
r2_3  <- summary(m3)$r.squared

adj1 <- summary(m1)$adj.r.squared
adj2 <- summary(m2)$adj.r.squared
adj3 <- summary(m3)$adj.r.squared

aic1 <- AIC(m1)
aic2 <- AIC(m2)
aic3 <- AIC(m3)

fit_df <- data.frame(
  model = c("Model 1", "Model 2", "Model 3"),
  R2 = c(r2_1, r2_2, r2_3),
  Adj_R2 = c(adj1, adj2, adj3),
  AIC = c(aic1, aic2, aic3)
)

print(fit_df)

# גרף R-squared
ggplot(fit_df, aes(x = model, y = R2)) +
  geom_col() +
  labs(
    title = "R-squared by model",
    x = "Model",
    y = "R-squared"
  ) +
  theme_minimal()

# גרף Adjusted R-squared
ggplot(fit_df, aes(x = model, y = Adj_R2)) +
  geom_col() +
  labs(
    title = "Adjusted R-squared by model",
    x = "Model",
    y = "Adjusted R-squared"
  ) +
  theme_minimal()

# גרף AIC
ggplot(fit_df, aes(x = model, y = AIC)) +
  geom_col() +
  labs(
    title = "AIC by model",
    x = "Model",
    y = "AIC"
  ) +
  theme_minimal()

# ============================================================
# חלק ד – Train / Test והערכת ניבוי
# ============================================================

# 1. חלוקה אקראית 80% / 20%
n_total <- nrow(df)
train_index <- sample(1:n_total, size = 0.8 * n_total)

df_train <- df |> slice(train_index)
df_test  <- df |> slice(-train_index)

# 2. התאמת מודלים על סט האימון
m1_tr <- lm(exam_score ~ study_time, data = df_train)

m2_tr <- lm(
  exam_score ~ study_time + test_anxiety + sleep_quality,
  data = df_train
)

m3_tr <- lm(
  exam_score ~ study_time + test_anxiety + sleep_quality +
    dominant_hand + music_preference + screen_time_weekend,
  data = df_train
)

# 3. ניבויים לסט הבדיקה
pred1 <- predict(m1_tr, newdata = df_test)
pred2 <- predict(m2_tr, newdata = df_test)
pred3 <- predict(m3_tr, newdata = df_test)

# 4. חישוב סכום שגיאות ריבועיות (SSE)
sse1 <- sum((df_test$exam_score - pred1)^2)
sse2 <- sum((df_test$exam_score - pred2)^2)
sse3 <- sum((df_test$exam_score - pred3)^2)

sse_df <- data.frame(
  model = c("Model 1", "Model 2", "Model 3"),
  SSE = c(sse1, sse2, sse3)
)

print(sse_df)

# 5. גרף איכות ניבוי (SSE)
ggplot(sse_df, aes(x = model, y = SSE)) +
  geom_col() +
  labs(
    title = "Prediction error (SSE) on test set",
    x = "Model",
    y = "Sum of squared errors"
  ) +
  theme_minimal()
