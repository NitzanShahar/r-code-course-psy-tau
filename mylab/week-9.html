8.5התאמת רגרסיה לוגיסטית

הנחיה למתרגל AI

שימוש ברגרסיה לוגיסטית באמצעות glm
1. הסבר לי במילים פשוטות מהי רגרסיה לוגיסטית ולמה משתמשים בה (למשל לנבא תוצאה בינארית: הצלחה/כישלון, כן/לא).
2. הראה בדוגמה קטנה איך יוצרים נתוני סימולציה: משתנה תלוי בינארי (0/1) ומשתנים מסבירים (מספריים או קטגוריים).
3. הדגם בקצרה באמצעות קוד R כיצד קוד glm אשר יעשה התאמה של רגרסיה לוגיסטית.
4. הדגם כיצד ניתן לצפות במקדמים של רגרסיה לוגיסטית באמצעות summary
5. בקש ממני לכתוב שורת קוד שתעשה שימוש ברגרסיה לוגיסטית. בדוק את התשובה שלי ועזור לי להבין אם יש טעות.
6. כתוב ששלב הלימוד הסתיים
עשה את השלבים האלו אחד אחד לפי הסדר. עצור בסוף כל שלב לראות שהבנתי והצלחתי, ורק אז המשך לשלב הבא.

1. כעת בקש ממני לכתוב קוד עם פקודת predict אשר יוסיף לנתונים את הערך המנובא מהרגרסיה הלוגיסטית. לאחר שאתנסה הסבר לי את ארגיומנט הtype ומדוע הוא חשוב כאשר מדובר ברגרסיה לוגיסטית. בודק שהבנתי ועזור במידת הצורך.

y_predicted = ifelse(prob_predicted>= 0.5, 1, 0)
1. הסבר לי כיצד ניתן לעשות שימוש בפקודת table עם ארגיומנט הpredicted והactual כדי לקבל confusion matrix

המטלה השבועית

המטלה השבועית (שבוע 9)

קובץ נתונים- מחלת לב

מידע על סט הנתונים: הקובץ מכיל נתונים אמיתיים על חולי לב.

משתנים:

  1. age : גיל הנבדק
  2. sex : מין הנבדק
  3. restbps : לחץ הדם של הנבדק במנוחה
  4. chol : כולסטרול בדם בעת הבדיקה (mg/L)
  5. bs : רמת סוכר בדם בעת הבדיקה
  6. maxhr : דופק גבוה ביותר שנמד
  7. target : האם אירע לנבדק אירוע לבבי

קובצי נתונים: heart.csv

חלק א – הכנת הנתונים

  1. טענו את קובץ הנתונים וחיקרו את טיבו במספר פקודות
  2. הגדירו משתנה חדש בינארי  המקבל ערך 1 כאשר רמת הסוכר בדם ≥ 120 ו‑0 אחרת.
  3. חלקו את המסד לשני מסדי נתונים:

הראשון יקרא df_training והוא יכיל כ70% מהתצפיות

השני יקרא df_test והוא יכיל כ30% מהתצפיות

  1. וודאו את מספר ואחוז התצפיות בכל מבנה נתונים

חלק ב – התאמת המודל

  1. התאימו מודל רגרסיה לוגיסטית על מסד נתוני האימון (df_training) שבו אירוע לבבי  הוא המשתנה התלוי ואילו שאר המשתנים (כולם או חלקם לבחירתך) בקובץ הם המשתנים המנבאים.

חלק ג – הערכת ביצועים

  1. חשבו את ההסתברויות החזויות למדגם הבדיקה (df_test) עבור כל תצפית.
  2. קודדו משתנה מנובא לסיכוי גבוה / נמוך למחלת לב לפי סף סיכוי של 0.5
  3. הדפיסו Confusion Matrix

בונוס (רשות):

  1. הוסיפו בחלק ב שורת קוד אשר תדפיס את מקדמי הרגרסיה
  2. הוסיפו בחלק ג חישוב של AUC, ואחוזי דיוק עבור אלו שחלו (רגישות) ואלו שלא חלו (סגוליות)
  3. צרו תרשים ROC עבור מדגם הבדיקה. תנו כותרת איור, וכתבו תוויות לצירים: “False Positive Rate” ו‑“True Positive Rate”.

כותרות הקוד: השתמשו בפורמט הכותרות של הקורס, וכתבו בתחילת הקובץ את שם הקורס, השבוע, מספר תעודת הזהות שלכם ושמכם.

פורמט ההגשה: קובץ PDF עם הקוד שכתבתם.

#### Part A – Data preparation ---------

# 1. Load the data and basic inspection
df <- read.csv("heart.csv")

head(df)
str(df)
summary(df)

# 2. Create a binary variable for blood sugar level
df$bs_high <- ifelse(df$bs >= 120, 1, 0)

# 3. Split the data into training (70%) and test (30%)
set.seed(123)
n <- nrow(df)
train_index <- sample(1:n, size = 0.7 * n)

df_training <- df[train_index, ]
df_test     <- df[-train_index, ]

# 4. Check number and proportion of observations
nrow(df_training)
nrow(df_test)

nrow(df_training) / n
nrow(df_test) / n


#### Part B – Model fitting ----

# Logistic regression model
model <- glm(
  target ~ age + sex + restbps + chol + bs_high + maxhr,
  data = df_training,
  family = binomial
)

# Bonus: print regression coefficients
summary(model)


#### Part C – Model evaluation ----

# 1. Predicted probabilities for the test sample
df_test$pred_prob <- predict(
  model,
  newdata = df_test,
  type = "response"
)

# 2. Classify using a 0.5 probability threshold
df_test$pred_class <- ifelse(df_test$pred_prob >= 0.5, 1, 0)

# 3. Confusion Matrix
table(
  Actual = df_test$target,
  Predicted = df_test$pred_class
)


#### Bonus -----


# AUC
library(pROC)

roc_obj <- roc(df_test$target, df_test$pred_prob)
auc(roc_obj)

# Sensitivity and specificity
cm <- table(df_test$target, df_test$pred_class)

sensitivity <- cm["1","1"] / sum(cm["1",])
specificity <- cm["0","0"] / sum(cm["0",])

sensitivity
specificity

# ROC curve
plot(
  roc_obj,
  main = "ROC Curve – Test Sample",
  xlab = "False Positive Rate",
  ylab = "True Positive Rate"
)

# ============================================================
# חלק א – הכנת הנתונים

# 1. טעינת הנתונים ובדיקת מבנה
df <- read_csv("data/heart_data.csv")

head(df)
str(df)
dim(df)

# 2. יצירת משתנה בינארי לרמת סוכר
df <- df |>
  mutate(
    high_sugar = ifelse(blood_sugar >= 120, 1, 0)
  )

# 3. חלוקה ל-Training / Test (70% / 30%)
n <- nrow(df)
train_index <- sample(1:n, size = 0.7 * n)

df_training <- df |> slice(train_index)
df_test     <- df |> slice(-train_index)

# 4. בדיקת מספר ואחוז תצפיות
cat("Training set:", nrow(df_training),

  data = df_training,
  family = binomial()
)

# בונוס – הדפסת מקדמים
print(coef(model))

  newdata = df_test,
  type = "response"
)

# 2. קידוד מחלקה לפי סף 0.5
pred_class <- ifelse(pred_prob >= 0.5, 1, 0)

# 3. Confusion Matrix
conf_mat <- table(
  Predicted = pred_class,
  Actual    = df_test$heart_event
)

print(conf_mat)

# ============================================================
# בונוס – AUC, רגישות, סגוליות ו-ROC
# ============================================================

# חישוב ROC ו-AUC
roc_obj <- roc(df_test$heart_event, pred_prob)
auc_value <- auc(roc_obj)

cat("AUC:", auc_value, "\n")

# רגישות וסגוליות מתוך Confusion Matrix
TP <- conf_mat["1", "1"]
TN <- conf_mat["0", "0"]
FP <- conf_mat["1", "0"]
FN <- conf_mat["0", "1"]

sensitivity <- TP / (TP + FN)
