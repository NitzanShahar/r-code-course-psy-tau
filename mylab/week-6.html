חלק א - טעינת ואיחוד קבצים.

  1. עשו שימוש בלולאת for על מנת להעלות ולאחד את קבצי הסטרופ של כל הנבדקים לקובץ אחד.

חלק ב - ניקוי נתונים ואיתור Outliers

  1. צרו פונקציה שלכם שמסמנת זמני תגובה חריגים.
    • הפונקציה מקבלת כקלט וקטור של זמני התגובה.
    • מחשבת ממוצע וס"ת לזמני התגובה שהוזנו בה.
    • מייצרת וקטור לוגי שמסמן כTRUE כל זמן תגובה שהוא גדול מממוצע זמני התגובה + 2 סטיות תקן.
    • פולטת את הוקטור הלוגי שמסמן זמני תגובה חריגים
  2. עברו עם לולאת for על מבנה הנתונים וסמנו ערכים חריגים בעזרת הפונקציה שלכם, שצריכה לחשב ממוצע וס"ת לכל נבדק. סימו לב שלשם כך עליכם:
    • להזין לפונקציה שיצרתם רק את זמני התגובה של כל נבדק, לפי הסדר
    • לשמור את הפלט של הפונקציה
    • לאחד את הוקטור שמסמן זמני תגובה לאותו נבדק, עם וקטור כללי שמכיל זאת עבור כל הנבדקים.
    • התוצאה צריכה להיות הוספת עמודה במבנה הנתונים העיקרי, שמסמנת זמני תגובה חריגים לכל נבדק, לפי ממוצע וס”ת האינדוודואלים שלו.

#### LOADING & MERGING FILES ----

library(tidyverse)

# 1. Get list of files
file_list = list.files(path = "stroop_data", pattern = "*.csv", full.names = TRUE)

df = data.frame()

for (file in file_list) {
  df_temp = read_csv(file, show_col_types = FALSE) |> as.data.frame()
  df      = bind_rows(df, df_temp )
}


# 2. Count subjects and stimulus types
n_subjects   = df |> pull(subject) |> n_distinct()
n_conditions = df |> pull(condition) |> n_distinct()

cat("Number of subjects:", n_subjects, "\n")
cat("Number of conditions:", n_conditions, "\n")


# 3. Count and percent of missing RTs
missing_summary = df |> 
  summarise(
    n_missing = sum(is.na(RT)),
    p_missing = mean(is.na(RT)) * 100
  )

print(missing_summary)


# 4. Plot RT histograms for congruent vs incongruent

flag_outliers = function(rt) {

  mu     = mean(rt, na.rm = TRUE)
  sigma  = sd(rt, na.rm = TRUE)
  index  = rt_vector > (mu + 2 * sigma)

  return(index)
}
